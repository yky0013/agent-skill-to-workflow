# Python 技能工作流工作台

> 历史设计：人工审核需求已被用户取消。当前实现遵循 `../plans/2026-11-05-inventory-without-review.md`，使用纯技能流程并自动显示本机 Skills、MCP、插件列表。

## 目标与依据

将仓库的「把 skill 串联起来，加入人工引导和审核」落实为可运行的桌面工作台与 CLI。用户选择本轮优先技能编排、人工审核与组合 skill 导出，要求优先使用 Python、Java、C 或 C++。

已有筛查资料区分了源文件、同名入口、历史运行证据、显式调用/转交关系及缺失资源。本轮读取该类 atlas.json，但不把历史检查当作当前成功运行，不向仓库提交用户的技能正文或本机目录数据。

## 实现选择

- 采用 Python 3.11+、Tkinter 原生桌面界面、PyYAML 安全解析与标准库 unittest。新的产品代码不使用 Rust、TypeScript 或 JavaScript。
- 在新克隆的仓库专用分支增加独立工作台，保留现有 Tauri 应用。继续扩展 Tauri 会增加用户不希望采用的语言；完整重写旧配置/聊天管理器超出本轮核心闭环。
- 应用入口 `python -m skill_workflow gui`，同一核心提供 scan/validate/export/run/status/complete/review CLI。

## 用户流程

1. 选择一个或多个技能根目录进行只读扫描，或读取既有 atlas.json。按名称/用途描述搜索，显示路径、静态问题、历史状态及其时间。
2. 选择 skill 添加工作流步骤，编辑任务说明、产物要求、步骤顺序；插入人工审核步骤，填写审核标准。
3. 保存、载入工作流 JSON；验证引用、重复步骤 ID、依赖缺失、环路、源文件变化与禁用入口。
4. 启动一次本地跟踪运行；skill 步骤由用户或宿主 agent 实际执行，用户登记产物与完成说明。该应用不执行 skill 文本或任意命令，也不声称调用了模型。
5. 人工审核通过后才放行下游；拒绝时保持阻塞，可补充说明后重新通过。状态和事件持久保存，可关闭后重新打开，不会隐式跳过审核。
6. 预览生成的 SKILL.md、workflow.json 和来源锁定信息，导出到新的技能目录。导出包含步骤输入、预期产物、依赖和人工审核要求；原技能文件保持只读。

## 核心约束

- 工作流 schemaVersion=1，包含 name、description、steps。步骤含 id、kind(skill/review)、title、depends_on、instruction、outputs；skill 步骤附 skill_path、skill_sha256。审核步骤附 criteria。
- UI 提供顺序编排；核心和 CLI 接受 DAG，以拓扑顺序生成指导。审核只能由显式 review 操作通过；complete 不得接受审核步骤。
- 工作流启动或导出时校验源文件。哈希不匹配/文件不存在属于阻塞错误；既有 atlas 的历史状态与本次静态检查分开显示。导入后复读源文件，不恢复执行任意脚本。
- 不将名称作为唯一键；ID 由路径生成。同名 skill 可以并存，显式选择路径。未知 schema、坏 JSON/YAML、循环依赖和非法字段产生可读错误。
- 生成的文件不自动安装。新目录导出使用暂存目录后改名，目标已存在时拒绝覆盖；JSON 状态写入使用原子替换，覆盖前保存备份，并校验预期旧内容防止丢失修改。
- 路径与名称校验；不跟随递归目录链接；扫描忽略 .git/node_modules/venv 等依赖目录。文件写入仅针对用户明确选择的工作流/运行/导出位置。
- 界面以中文为主。复杂操作使用后台扫描避免冻结界面；错误在界面可见。原文与导出预览用纯文本显示。

## 构建审阅后的明确约定

- 导出 `SKILL.md` 必须有 YAML `name`、`description`；逐步列出依赖、任务说明、产物、绝对来源路径和 SHA-256。`sources.lock.json` 记录去重来源。导出的指令要求宿主在每个审核点等待本次运行的用户明确通过，不能把历史通过当作本次通过。应用内状态机强制阻塞；导出文本仍依赖宿主遵循指令，不能保证外部宿主的执行行为。
- 兼容既有 atlas schemaVersion=1 的 `skills[].path/sha256/enabled/visibility/historical/references` 和顶层 `capturedAt`。只有源哈希一致才复用显式引用证据；历史运行状态永远标为历史。`enabled=false` 或 `visibility=disabled` 是快照禁用证据，选择时阻塞；目录扫描不推断宿主启用状态，标为未知。
- JSON 新建/保存/状态变更和恢复均展示差异。GUI 确认差异后写入；CLI 默认预览，显式 `--apply` 才写。覆盖前自动备份；提供从备份恢复 JSON 的入口。读取和最终写入之间用预期摘要和排他锁阻止本应用并发覆盖。
- 主文件锁定不覆盖脚本/资源目录全部内容；缺失 Markdown 链接是警告，可能属于可选分支。应用不会推断未被明确声明的调用关系。

## 本轮边界说明

这是编排、人工跟踪与生成组合技能的工具，不是无人值守代理执行平台。模型调用、远程调度、自动执行脚本、付费服务、自动删除技能和完整旧应用迁移不在本轮实现。导出的组合技能依赖原 skill 路径；跨设备时须在目标机器重新选择技能并导出。
