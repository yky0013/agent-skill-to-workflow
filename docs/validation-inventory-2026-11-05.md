# 0.2.0 本机清单与纯技能流程验证

本版本移除了人工审核步骤，补齐默认启动的 Skills、MCP 和插件列表。

## 自动化与真实数据

- Windows / Python 3.14 / PyYAML 6.0.3，隔离环境执行 `python -m unittest discover -s tests -v`：83 项通过，无失败、无跳过。
- 覆盖纯技能步骤推进、事件与状态一致性、v1 依赖图迁移、旧运行拒绝、审核命令移除、导出文件、默认启动、自选目录、扫描竞争、MCP/插件结构、禁用状态继承及凭据隐藏。
- 独立审查发现的五类问题已修复：MCP 内联命令中的敏感信息、禁用插件下技能状态、切换来源后禁用状态丢失、启动切换导致 MCP/插件列表丢失，以及隐式扫描当前工作目录。
- 真实本机数据初始化检查：Skills 212 行、MCP 11 行、插件 28 行，默认选中 Skills 页面，审核按钮与标准编辑器不存在。MCP 数量包含用户配置与插件声明，不代表连接成功数量。
- 当前扫描发现 24 个技能根目录。插件列表中 12 个有配置启用记录，16 个只从缓存发现，启用状态未知。历史档案及无有效插件清单的备份目录不作为当前入口加入。
- 双技能样例已生成 schema v2 工作流并实际导出；只含 skill 节点，生成的 SKILL.md 无审核或等待批准关卡。

## 文件与状态保护

- 本次发现过程只读，未修改用户 config.toml、插件配置、源技能或 MCP 服务。
- 旧工作流先验证依赖，再在内存中移除 review 节点并重接依赖；原文件只有明确保存后才改变。
- 旧 v1 运行文件不自动转成成功记录；使用新工作流创建 v2 运行。
- 配置、历史 atlas、真实列表和本机执行记录均留在 ignored 的 `.workflow-local` 或原位置，没有进入仓库提交。
